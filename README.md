# Memories — Killer Beach

Killer Beach のメンバーが観た・聴いた・行ったものを記録するコレクションサイト。
映画、音楽、アート、ライブ、本、ゲーム、建築。評価と一言メモ付き。

メンバーは記録用 Google Sheet に1行足すだけでサイトに反映されます（シートは非公開）。
運用の詳細は [BAND.md](BAND.md) を参照。

Forked from chaseaux/memories (personal edition, Notion-backed) and reworked
for the band: Google Sheets log, member filters, Killer Beach brand skin.
